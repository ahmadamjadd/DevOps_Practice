# DevOps Practical Course — Notes & Exercises

**Overview**
- This repository contains practical work and exercises for my DevOps practical course (assignments, labs, scripts, containers, IaC, CI/CD and small apps).

**What I Learned**
- Docker
- Docker Compose
- Bash scripting
- Shell programming
- Linux system administration
- SSH and key management
- LAMP stack (Apache, MySQL, PHP)
- Terraform (AWS)
- CI/CD & GitHub Actions
- Containerizing ML and web applications
- Web frontend and backend basics (React/Vite, Python)
- Monitoring and system auditing
- Deployment and automation
- AWS (EC2, ECS, IAM, VPC, S3)
- Git

**Contents**
- **Assignments & Labs:** practical exercises and writeups across Assignment1..Assignment6, Lab-02..Lab-07.
- **Scripts:** many Bash scripts for automation, backup, system info and user management.
- **Containerization:** Dockerfiles, Docker Compose and multi-container examples.
- **Infrastructure:** Terraform code for basic AWS resources.
- **CI/CD:** example GitHub Actions workflows used for testing and staging.

**How to use this repo**
- Browse folders by assignment or lab to find code and notes.
- Run scripts locally only after reviewing them; many are intended for learning and may require sudo or specific environments.
